## ショアキーパーがチーム構築を変える理由

ショアキーパーは、手持ちの全員の火力を引き上げる稀有なサポートです。彼女を実装時や後の復刻で引いたなら、次に必ず浮かぶ疑問は同じでしょう。理想のショアキーパーチームとは実際どんな形なのか？ 短く言えば、彼女はほぼどこにでも収まります。ただし、いくつかの編成は彼女のキットから他の追随を許さないほど大きな価値を引き出します。本ガイドでは、最強のショアキーパーチーム構成、それをきれいに回す方法、そして手持ちに重要な星5がいない場合でも機能する低予算オプションを解説します。

彼女は2024年9月29日、バージョン1.3で登場し、その後も復刻ガチャで再登場しています。そのため、低投資のまま明確な計画もなく放置しているプレイヤーも少なくありません。それはもったいない話です。ショアキーパーは、チームの弱点を補うだけでなく、チームの上限そのものを引き上げる数少ないユニットです。

## ショアキーパーがチームにもたらすもの

ショアキーパーは黒海岸の守護者として知られる回折属性の共鳴者で、場を安定させながら次に登場するキャラのダメージを増幅することに特化したヒーラー兼バッファーです。彼女の価値は自身の生のダメージではなく、退場時に引き渡す会心中心のバフ群にあります。

コミュニティWikiに記載されている彼女のアビリティ名は、そのまま彼女の操作方法に対応するため、覚えておく価値があります。

| アビリティ | 種類 | ショアキーパーチームでの役割 |
| --- | --- | --- |
| オリジン・カルキュラス | 通常攻撃 | 待機時間を埋め、共鳴回路ゲージの蓄積を助ける |
| カオス・セオリー | 共鳴スキル | 中核となる準備手段であり、回復のトリガー |
| エンド・ループ | 共鳴解放 | チームを維持する持続的なフィールド効果を生成 |
| アストラル・コード | 共鳴回路 | ゲージが溜まると回復量が強化 |
| ライフ・エンタワインド | 固有スキル | 持続回復に関するパッシブボーナス |
| セルフ・グラビテーション | 固有スキル | 自身のスケーリングを支えるパッシブステータス |
| プルーフ・オブ・エグジステンス | 登場スキル | 交代で登場時にダメージと回復 |
| バイナリ・バタフライ | 退場スキル | 交代で退場時にチーム全体へ会心バフと回復 |

要点は、彼女の退場スキルこそがチームに入れる理由だということです。会心率と会心ダメージのバフはすべてのダメージディーラーに同時に適用されるため、ショアキーパーへの投資は1キャラではなくアカウント全体で報われます。

### 会心バフがそれほど重要な理由

『鳴潮』のほとんどのダメージディーラーは、すべての音骸で会心厳選を追い求めます。会心ステータスを無償で配るサポートがいれば、アタッカーは代わりに攻撃力とダメージバフを積めます。これが、ショアキーパーチームが純粋なヒーラーを同枠に入れた同じチームよりダメージで上回りやすいメカニズム上の理由です。

## 最高のショアキーパーチーム編成

基本の型は一貫しています。メインダメージディーラー1人、サブDPSまたは協同攻撃パートナー1人、そしてショアキーパーです。変わるのは、どの属性を強化するかと、DPSがどれだけ場に立つ必要があるかです。

| チーム | メインDPS | 自由枠／サブDPS | 機能する理由 |
| --- | --- | --- | --- |
| 回折ハイパーキャリー | 今汐 | 折枝、吟霖、またはヴェリーナ | 協同攻撃が今汐のインカンデセンススタックを供給 |
| 消滅バースト | カメリア | 散華、ロココ、丹瑾 | 散華の速い退場サイクルがカメリアの短い火力時間に合う |
| 気動ブルーザー | 忌炎 | モルトフィー、アルト | モルトフィーの協同攻撃が忌炎の長い共鳴解放と噛み合う |
| 熱熔キャリー | 長離 | アンコ、ルパ | クイックスワップの熱熔ダメージは常時の会心バフ維持で伸びる |
| 電導バースト | 相里要 | 吟霖 | 吟霖の印が単発高火力の共鳴解放を増幅 |
| 凝縮スナイパー | カルロッタ | 折枝、ルミ | 遠距離の安全な立ち回りと会心バフで安定した火力 |
| 低予算漂泊者 | 漂泊者（消滅） | 丹瑾、散華 | エンドコンテンツも攻略できる無課金向けの核 |

### 今汐＋ショアキーパー

多くのプレイヤーが最初に思い浮かべる組み合わせです。今汐は協同攻撃を発動できる、あるいは回折に近い異なる効果を付与してインカンデセンスを溜められる仲間を求めます。ショアキーパーのバフ時間は、今汐のチャージバーストとぴったり噛み合います。折枝を持っているなら彼女が自然な3枠目です。折枝を別チームで使っている場合は吟霖でも機能します。

### カメリア＋ショアキーパー

カメリアのダメージは会心への依存度が非常に高いため、ここではショアキーパーの退場スキルの価値が際限なく高まります。散華は速いローテーションと通常攻撃強化により、今なお最も安価で強力なパートナーです。コミュニティの報告では、この3人組は多くのアカウントで組める中でも屈指の高ダメージチームとして常に上位に挙げられています。

### 忌炎＋ショアキーパー

忌炎は共鳴解放状態で長く戦うため、数秒だけでなくウィンドウ全体にバフをかけられるサポートが理想的です。モルトフィーは協同攻撃を提供し、アルトは代用できる低予算枠です。

## ローテーション：実際にチームをどう動かすか

ショアキーパーチームはローテーション順で生死が決まります。彼女のバフは退場時にしか付与されないため、戦闘終了時に彼女が場にいる状態は避けたいところです。

| 手順 | 行動 | 目的 |
| --- | --- | --- |
| 1 | ショアキーパーの登場スキルから共鳴スキルへ | 準備を付与し、回復を開始 |
| 2 | 通常攻撃で共鳴回路をチャージ | 強化回復を準備 |
| 3 | 共鳴解放 | フィールド効果を展開 |
| 4 | 退場スキルで交代 | DPSに会心バフを渡す |
| 5 | メインDPSのバースト時間 | バフを最大ダメージに使う |
| 6 | サブDPSの退場チェーン | 次のバッファーへつなぐ |
| 7 | ショアキーパーへ戻る | バフが切れる前に更新 |

彼女の場にいる時間は短く保ちましょう。ショアキーパーが攻撃している1秒は、ダメージディーラーが攻撃していない1秒です。実際には、きれいなローテーションなら彼女が場にいるのは長くても数秒です。

## 音骸、武器、ステータス優先度

ショアキーパーのスケーリングは共鳴効率とHPを重視するため、まずサポートとして育成し、ダメージステータスを与えたくなる誘惑に抗いましょう。

| 枠 | 推奨 | 備考 |
| --- | --- | --- |
| 4コスト音骸 | ファラシー・オブ・ノーリターン | チーム攻撃力バフによりコミュニティで好まれる |
| 3コスト音骸 | 共鳴効率メインステータス | まず彼女の共鳴効率の必要値達成を優先 |
| 1コスト音骸 | HP%メインステータス | 回復量と生存性を改善 |
| サブステータス | 共鳴効率 > HP% > 固定HP | 回復効果アップは良い追加厳選 |
| セット効果 | リジュビネイティング・グロウまたはムーンリット・クラウズ | 回復特化かチームバフ特化 |

| ステータス | 優先度 | 理由 |
| --- | --- | --- |
| 共鳴効率 | 最優先 | 毎ローテーションで共鳴解放を保証 |
| HP% | 高 | 回復量に直接スケール |
| 会心ステータス | 低 | 彼女はダメージ源ではない |
| 攻撃力% | 低 | サポート価値への影響は最小 |

プレイヤーの経験則では、各サイクルで無理なく共鳴解放を撃てるだけの共鳴効率を目指し、その後はHPを積んで止めるのがよいとされています。ショアキーパーに会心ステータスを過剰投資するのは、最もよくあるビルドミスの一つです。

## 低予算・無課金向けショアキーパーチーム

彼女を機能させるのに星5だらけの手持ちは必要ありません。いくつかの星4ユニットが彼女と好相性です。

| 低予算チーム | メンバー | 備考 |
| --- | --- | --- |
| スターター消滅 | 漂泊者（消滅）＋丹瑾＋ショアキーパー | 完全に入手可能で、単体火力が高い |
| 熱熔の基本 | 熾霞＋アンコ＋ショアキーパー | 熾霞は序盤の安定したキャリー |
| 凝縮コントロール | 散華＋釉瑚＋ショアキーパー | 強力な群制御と持続力 |
| 電導つなぎ | 淵武＋ブーリン＋ショアキーパー | 育成が安く、周回向き |
| 気動低予算 | 秧秧＋アルト＋ショアキーパー | エネルギー生成でローテーションが滑らか |

彼女のガチャはこれまで、白芷、散華、アルト、桃祈、秧秧、熾霞などの星4を同時排出してきたため、多くのプレイヤーは追加課金なしですでに機能するショアキーパーチームのパーツを揃えています。

## 避けるべきよくあるミス

- **ショアキーパーを場に長く置きすぎる。** 彼女のダメージは無視できるほどで、バフがすべてです。
- **退場スキルを省略する。** 退場スキルで交代することがこのキャラの存在意義そのものです。
- **ショアキーパーに会心を積む。** そのステータスはDPSにこそ必要です。
- **共鳴効率を無視する。** それがないと共鳴解放のサイクルが崩れ、ローテーションが破綻します。
- **ヒーラー2枚運用。** 戦闘を練習中でない限り、2人目のヒーラー枠はダメージに回したほうがよいです。
- **フィールド効果の更新を忘れる。** 長期戦ではバフが切れる前に共鳴解放を再発動しましょう。

パッチノート、ガチャスケジュール、公式キット資料については、[『鳴潮』公式サイト](https://wutheringwaves.kurogames.com/en/main) が最も信頼できる情報源です。

## よくある質問

**新規プレイヤーにとって最高のショアキーパーチームは？**
漂泊者（消滅）、丹瑾、ショアキーパーから始めましょう。3人とも入手しやすく、ローテーションも寛容で、重い投資なしにほとんどのストーリーと周回コンテンツをクリアできます。

**ショアキーパーはどんなメインDPSとも組めますか？**
はい。彼女のバフは属性固定ではなく会心ベースのため、回折、消滅、気動、熱熔、電導、凝縮の各チームに入ります。おそらくゲーム内で最も柔軟なサポートです。

**ショアキーパーチームにはどれくらい共鳴効率が必要？**
毎ローテーションで共鳴解放を撃てるだけの量です。プレイヤーの検証では、まず無理なく回せる共鳴効率のしきい値を目標にし、その後は回復量のためにHP%へ移行するのが一般的です。

**すでにヴェリーナを持っている場合、ショアキーパーを引く価値はある？**
ほとんどのアカウントでは、はい。ヴェリーナも優秀ですが、ショアキーパーの会心バフは純粋な回復ではできない形でチームのダメージ上限を引き上げます。両方持っていれば、別々のチームで強力なサポートを2枚運用できます。

**ショアキーパーチームはエンドコンテンツを攻略できますか？**
はい。適切に投資したメインDPSときれいなローテーションがあれば、ショアキーパーチームは塔形式のエンドコンテンツも快適に攻略できます。キャラの生のレベルよりもバフの維持時間のほうが重要です。

## 最後に

ショアキーパーは、彼女を中心に組むキャラではなく、彼女*を通して*組むキャラです。最も強いダメージディーラーを選び、その属性に合うサブDPSを加え、持続力と会心増幅はショアキーパーに任せましょう。共鳴効率を適正にし、場にいる時間を短くし、常に退場スキルを発動して離脱する。それを実践すれば、あなたのショアキーパーチームは、はるかに多くのコストをかけて組んだ編成をも上回るでしょう。
