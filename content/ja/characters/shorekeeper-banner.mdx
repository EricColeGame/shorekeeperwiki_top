鳴潮において、ショアキーパーほど長く議論を呼ぶキャラクターは少ない。彼女はスペクトロの共鳴者として登場し、その存在はプレイヤーのチーム構築を一変させた。そして限定5星であるため、**ショアキーパーガチャ**はKuro Gamesが復刻を予定した時にしか戻ってこない。一度逃せば、次の機会まで何ヶ月も待つことになるだろう。

だからこそ、**ショアキーパーガチャ**を追跡することが重要なのだ。前回いつ開催されたか、どの4星が一緒にピックアップされたか、そして集音がどのように構成されているかを知ることで、ギリギリで慌てて課金するのではなく、落ち着いて計画的な引きができるようになる。このガイドでは、彼女のガチャ履歴、性能、そして次回復刻に備えて今できる実践的なステップを紹介する。

## ショアキーパーとは？

ショアキーパーは、鳴潮でプレイアブルな光の共鳴者であり、そのゲーム内での立場が彼女の魅力を大きく物語っている。彼女は「第二のインスタンス」として知られ、黒海岸の守護者であり、ソノロ・スフィアと高純度のレムナント・エネルギー結晶で構成された神話的な存在とされている。

ゲームの設定によれば、彼女はテティス・システムを導き、星そのものを操る力を持ち、危機の時にのみ現れ、黒海岸の真の指導者を助けるという。組織の招待客やメンバーの間でも、彼女は非常に謎めいた存在であり続けている——それが彼女のガチャがこれほど大きな興奮を生む大きな理由の一つだ。

彼女の公式紹介では、あなたの召喚に応じて現れる神秘的な神的存在として描かれている。永劫の守護の時を経て、彼女は感情を育み、世界と——そしてあなたと——つながりたいという決意を抱くようになる。この物語的なフックが、初回をスキップしたプレイヤーがショアキーパーガチャの復刻をいつまでも待ち望む大きな理由である。

## ショアキーパーガチャ履歴：これまでの全イベント集音

限定共鳴者は通常の集音には追加されないため、ショアキーパーを入手する唯一の方法は、彼女専用のイベント集音**「海が晴れるまで」**である。以下が記録された開催履歴だ。

| 集音 | バージョン | 期間 | ピックアップ4星 |
| --- | --- | --- | --- |
| 海が晴れるまで | 1.3 | 2024年9月29日～10月24日 | 桃祈（闇）、秧秧（風）、熾霞（熱） |
| 海が晴れるまで | 2.2 | 2025年4月17日～4月28日 | 白芷（氷）、散華（氷）、アールト（風） |

記録に関する注意点：Wikiの入手可能性の概要では、ショアキーパーは3回のイベント集音でピックアップされたとされているが、そのガチャ表では完全に記録されているのは2回のみである。上記の表を確認済みのデータとして扱い、ガチャを引く予算を組む前に最新の情報をチェックしよう。

この2回の開催は、復刻のタイミングについての有益な教訓でもある。バージョン1.3での初登場ではプレイヤーに丸1ヶ月の引き期間が与えられたが、2.2での復刻はわずか約11日間しか続かなかった。このパターンが続くなら、今後のショアキーパーガチャの期間は短くなる可能性があるため、事前にアストライトを用意しておく方が、パッチ中に慌てるよりはるかに安全だ。

## ショアキーパーガチャ復刻時に予想されること

鳴潮の復刻集音は、一般的に初登場のガチャと同じ構造に従うが、いくつか理解しておくべき実践的な違いがある。

### ピックアップ4星のラインナップ

上記の履歴が示すように、4星のラインナップは開催ごとに変わる。初登場時は、桃祈、秧秧、熾霞と一緒に引くことができた。復刻では白芷、散華、アールトに入れ替わり、よりサポートと耐久に重点を置いたラインナップとなった。

コミュニティの報告によれば、このローテーションは意図的なものである：復刻ではしばしば、限定5星と彼女のチームでの役割を補完する4星が組み合わされる。すでに桃祈や白芷を高凸で持っている場合、ガチャの価値はそれに応じて変化する。

### 天井、確定、引き継ぎ

| 仕組み | 一般的な動作 |
| --- | --- |
| 引くための通貨 | アストライトを集音の引きに変換 |
| 天井カウンター | 限定キャラクターガチャ間で引き継がれる |
| 確定 | 50/50に負けると、通常は次の限定5星が確定する |
| ガチャの分離 | キャラクター集音の天井は武器集音には適用されない |

天井は限定キャラクターガチャ間で引き継がれるため、ショアキーパーガチャが復刻する前に別の5星に使った引きは無駄にはならない。多くのプレイヤーは、なくても困らないガチャで意図的に天井を積み、ショアキーパーが復刻した時にそれを完了させる。

### 同時開催の武器集音

キャラクターガチャには通常、その共鳴者の専用武器がピックアップされた武器集音が伴う。武器の天井は別々に管理されるため、キャラクターと武器の両方を欲しい場合は、2つの予算を計画する必要がある——1つではない。プレイヤーの経験から、ショアキーパーの価値は主にチームでの役割から来るので、生のダメージ出力よりもキャラクターを優先することが一貫して推奨されている。

ほとんどのアカウントにとって、はい——しかし正直な答えは、あなたの手持ちがすでに何を得意としているかによる。ショアキーパーはコミュニティで広くサポート指向の光の共鳴者と見なされており、特定のダメージディーラーに縛られることなく、幅広いチーム構成で価値がある。

### 優先して引くべき人

- **新規プレイヤー**で最初の本格的なチームを構築する人。柔軟なサポートは様々なコンテンツで活躍するため。
- **高難度のエンドゲームモードで行き詰まっているプレイヤー**で、より堅牢で安定したバックボーンを必要とする人。
- **コレクターや設定ファン**で、黒海岸のストーリーを追い、その中心にいるキャラクターを欲しい人。

### スキップしても問題ない人

- すでに2体以上の育成済みサポートを所持しており、すべてのコンテンツを快適にクリアできるプレイヤー。
- 発表済みの今後の共鳴者で、より欲しいキャラクターのために積極的に貯蓄している人。

## 次のショアキーパーガチャに備える方法

準備が、ストレスのない引きとイライラする引きの間の最大の違いである。復刻が発表される前の数週間で、このチェックリストを使おう。

| ステップ | なぜ重要か |
| --- | --- |
| アストライトを貯める | 2.2の開催が示したように、復刻期間は短くなる可能性がある |
| 公式発表を追う | 復刻日は公式チャンネルでのみ確認される |
| 天井カウンターを確認する | 引きを決行する前に、必要な引き数を正確に把握する |
| 突破素材を事前に集める | キャラクターレベルとフォルテのアップグレードにはワールド素材が必要 |
| 凸を事前に決める | 初日に感情的に引きすぎるのを防ぐ |
| 厳格な上限を設定する | 次の限定キャラクターのために貯蓄を守る |

彼女に関連するストーリーコンテンツをプレイすることも役立つ。ショアキーパーは、第1章第8幕「To the Shore's End」、第2章プロローグ「Through the Sea Thou Break」、第3章プロローグ「When the Unknown Thrums」に登場する。期間限定イベントのCube, Cubic n CubieやMemory Travelogueでも彼女はフィーチャーされているので、追加の設定や報酬のためにイベントの復刻にも注目しよう。

最後に、[鳴潮公式サイト](https://wutheringwaves.kurogames.com/)をブックマークして、ガチャの発表を二次情報で知るのではなく、発表された瞬間にキャッチできるようにしよう。

## よくある質問

**ショアキーパーガチャはいつ復刻しますか？**

決まったスケジュールはない。記録されている開催はバージョン1.3（2024年9月～10月）とバージョン2.2（2025年4月）だ。Kuro Gamesは公式発表でのみ復刻を確認するので、次のバージョンの集音ラインナップにショアキーパーガチャが現れるか、パッチのライブ配信をチェックしよう。

**新規アカウントでショアキーパーガチャは引く価値がありますか？**

ほとんどの新規プレイヤーにとって、はい。彼女は柔軟な光のサポートであり、多くのチーム構成に適合するため、手持ちが増えても貢献し続ける。主な例外は、すでに特定の今後のキャラクターのために貯蓄している場合だ。

**ショアキーパーガチャの開催間で天井は引き継がれますか？**

はい。限定キャラクター集音の天井は、復刻を含むガチャ間で引き継がれる。つまり、他の限定ガチャに使った引きも次の5星にカウントされ、50/50に負けると通常は次に引く限定キャラクターが確定する。

**ショアキーパーの元素と役割は何ですか？**

彼女は光の共鳴者で、設定上は第二のインスタンスと黒海岸の守護者として知られている。コミュニティの総意では彼女はサポート役とされており、だからこそ、別の純粋なダメージディーラーよりも、耐久性があり柔軟なバックボーンを必要とするアカウントによく推奨される。

**専用武器も必要ですか？**

必ずしもそうではない。武器集音は別の天井を使用するため、両方を追うと予算が2倍になる。プレイヤーの経験から、まずキャラクターを確保し、アストライトが許すなら武器をオプションの追加として扱うことが推奨されている。
