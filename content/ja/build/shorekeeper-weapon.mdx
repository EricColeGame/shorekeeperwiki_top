ショアキーパーは、鳴潮の共鳴者の中でも、その価値のほとんどが「他者に何を与えられるか」で測られる数少ない存在です。彼女の回復、バフ、チーム全体の強化はすべて、ほんの一握りのステータスに由来します。つまり**ショアキーパー武器**はダメージを伸ばす棒ではなく、ローテーション全体の調整弁なのです。間違った武器を選べば、共鳴解放のウィンドウは縮まり、バフは薄まり、チームの全ダメージディーラーが静かに火力を落とします。

正しい武器を選べば、ダメージメーターのトップに立つことのないサポートが、クリアタイムを短くする理由になります。このガイドでは、**ショアキーパー武器**に本当に求められる役割、追う価値のあるステータス、そして不要なガチャに星声（アストライト）を溶かさずに彼女を育成する方法を解説します。

## ショアキーパー武器の基本：種類、役割、スケーリング

ショアキーパーは黒海岸（ブラックショア）出身の回折属性の共鳴者で、公式設定では漂泊者の呼びかけに応じて現れる守護者とされています。戦闘面では純粋なサポートであり、自身がダメージを担うのではなく、回復とバフでチームの他のメンバーを支えます。

| 項目 | ショアキーパー |
| --- | --- |
| 属性 | 回折 |
| 武器タイプ | 増幅器 |
| 戦闘役割 | サポート / ヒーラー / バッファー |
| 主要参照ステータス | HP |
| 副次優先ステータス | 共鳴効率 |
| 専用武器 | 星5増幅器（Stellar Symphony） |
| 初登場ガチャ | バージョン1.3、2024年9月 |
| 復刻時期 | バージョン2.2、2025年4月 |

彼女は増幅器使いなので、武器の選択肢は片手剣や長刃のキャラクターより狭くなります。増幅器は大きく3つの設計系統に分かれます。共鳴効率を伸ばすもの、HPスケーリングを伸ばすもの、攻撃力/クリティカル系を伸ばすものです。ショアキーパーのキットに合うのは最初の2つだけです。彼女の公式キット詳細やガチャ履歴を確認したい場合は、[鳴潮 公式サイト](https://wutheringwaves.kurogames.com/en/) から始めるのが最適です。

武器パッシブを評価する際には、彼女のキット名が重要になります。共鳴スキルは「カオス・セオリー」、共鳴解放は「エンド・ループ」、共鳴回路は「アストラル・コード」、終奏スキルは「バイナリー・バタフライ」です。共鳴スキル発動時や終奏スワップ時に発動する武器パッシブは、通常攻撃時に発動するものより彼女のローテーションにはるかに噛み合います。彼女は通常攻撃に割く時間がごくわずかだからです。

## ショアキーパーの武器で実際に重要なステータス

このガイド全体で最も重要な考え方はこれです。ショアキーパーの武器は、彼女自身のダメージのためではなく、共鳴解放のためにステータスを届ける装置です。これにより、いつもの優先順位は根本から逆転します。

| 優先度 | ステータス | 彼女にとっての効果 | 評価 |
| --- | --- | --- | --- |
| 1 | 共鳴効率 | エンドループの再充填を速め、バフフィールドを維持する | 必須 |
| 2 | HP% | 回復量とバフ値をスケーリングする | 価値が高い |
| 3 | 固定HP | HPスケーリングにわずかに寄与する | 小さいが歓迎 |
| 4 | 治療効果 | 回復量が増えるだけで、バフは伸びない | 状況次第 |
| 5 | 攻撃力% / クリティカル率 / クリティカルダメージ | サポートにはほぼリターンがない | 不要 |

共鳴効率が最上位なのは、ショアキーパーの有用性が共鳴解放の稼働率に直結しているからです。ダメージディーラーの火力ウィンドウが開くときにエンドループが準備できていなければ、ローテーション全体のタイミングがずれます。プレイヤー体験談では、共鳴効率は最初に軽視されがちなステータスであり、改善したときに最も大きな実感を得られるステータスだと一貫して報告されています。

HP%が2番目なのは、それが彼女のサポート出力の倍率になるからです。HP%のサブステータスと控えめなパッシブを持つ武器は、クリティカル系ステータスを持つ派手な武器よりもたいてい優れた結果を出します。ダメージを出さないキャラクターにとって、クリティカルは何もしないからです。

1つ注意点があります。特定の共鳴効率の数値を万能な目標値として扱わないでください。適切なしきい値は、チームのコンチェルト生成、音骸のサブステータス、2人目のサポートを編成しているかどうかによって大きく変わります。感覚で調整しましょう。エンドループが毎回のスワップサイクルで準備できているなら、十分です。

## 予算別ショアキーパー武器のおすすめ

彼女を機能させるために専用武器は必要ありません。以下では、最大投資の選択肢からつなぎ装備まで、現実的な選択肢を段階別に紹介します。

| 段階 | 選択肢 | 武器クラス | もたらすもの |
| --- | --- | --- | --- |
| 総合最強 | 専用増幅器（Stellar Symphony） | 限定星5 | HP%と共鳴効率、そしてチーム全体を支援するパッシブ |
| 強力な代替 | 標準ガチャ増幅器（Cosmic Ripples） | 標準星5 | 高い基礎ステータスと有用な共鳴効率、ただし攻撃力寄りのパッシブ |
| 最高コスパ | 共鳴効率増幅器（Variation） | 星4 | 共鳴効率サブステータスとサポート向けパッシブ — コミュニティ人気 |
| 回復重視 | HPサブステータス増幅器 | 星4 | 共鳴効率がすでに確保できている場合に回復量を高めるHP%サブステータス |
| 序盤 | 任意の星3増幅器 | 星3 | より良い武器を引くまでのつなぎ |

**専用武器の選択肢。** Stellar Symphonyは彼女のために作られています。HPと共鳴効率を1つにまとめ、さらにチームに何かを還元するパッシブを備えています。最もきれいに噛み合いますが、最も高価でもあります。彼女を長期的な編成の主力として使い続けると決めている場合にのみ引きましょう。

**標準ガチャの選択肢。** Cosmic Ripplesは、多くのプレイヤーが最初に手にする武器です。基礎ステータスが高く、共鳴効率にも貢献しますが、パッシブはショアキーパーには活かせない自身のダメージ寄りです。優れたステータス棒であり、星4からは確実なアップグレードです。

**低予算の選択肢。** Variationは、無課金ショアキーパービルドの大多数で採用されている武器です。共鳴効率のサブステータスが彼女の最も重要な要求を満たし、パッシブもダメージよりもサポート向けに寄っています。コミュニティでは、彼女の枠で最もコスパの良い選択肢として繰り返し名前が挙がります。

**回復重視の選択肢。** 音骸で共鳴効率がすでに解決しているなら、HPサブステータスの増幅器は回復量とバフ値をさらに高めます。これは調整段階の判断であり、出発点ではありません。

## ショアキーパー武器を軸にしたビルド方法

武器は単独で存在するものではありません。以下の要素が、ショアキーパーの武器が実際に性能を発揮できるかを決めます。

| ビルド枠 | 推奨重視項目 |
| --- | --- |
| 武器サブステータス | 共鳴効率を最優先、次にHP% |
| 4コスト音骸 | 共鳴効率メインステータスがあればそれ、なければHP%か治療効果 |
| 3コスト音骸 | HP%または共鳴効率 |
| 1コスト音骸 | HP% |
| 音骸サブステータス | 共鳴効率 > HP% > 固定HP |
| 音骸セット | 回復またはサポート向けセット（例：癒しの光） |

**ローテーションは装備と同じくらい重要です。** 装備が整っていてもローテーションが雑なショアキーパーは、装備がそこそこでもループが正確なショアキーパーに劣ります。

| 手順 | 行動 | 重要な理由 |
| --- | --- | --- |
| 1 | 別のユニットでコンチェルトを貯める | 素早いスワップの準備になる |
| 2 | スワップインしてカオス・セオリーを発動 | スキルクールダウンを早く開始できる |
| 3 | エンド・ループを発動 | 回復とバフのウィンドウを開く |
| 4 | 共鳴回路アストラル・コードを使用 | フィールドの持続時間を延長する |
| 5 | バイナリー・バタフライでスワップアウト | バフをダメージディーラーに引き継ぐ |

**チーム適性。** ショアキーパーは、短いバフ期間内に火力を吐き出したいバースト型ダメージディーラーと特に輝きます。彼女の共鳴解放ウィンドウ中に最大火力が着地するユニットと組み合わせ、継続的にダメージを出してタイミングをあまり気にしないキャラクターとは組ませないようにしましょう。

## ショアキーパー武器でよくある間違い

- **クリティカル武器を追う。** クリティカル増幅器はステータス画面では立派に見えますが、意味のあるダメージを出さないサポートにはほとんど何もしません。
- **共鳴効率を任意扱いする。** 彼女のキットが機能するかどうかを決める唯一のステータスです。それ以外はすべてボーナスです。
- **パッシブの発動条件を無視する。** 通常攻撃を要求するパッシブは、ショアキーパーではほとんど発動しません。数値だけでなく発動条件を読みましょう。
- **間違った武器を過剰に精錬する。** 精錬素材は有限です。何か月も実際に装備し続ける武器に使いましょう。
- **低予算の選択肢を試す前に専用武器を引く。** まず星4の共鳴効率増幅器を試しましょう。多くのプレイヤーはそれで十分だと感じ、そのガチャ石を別に回します。
- **彼女のガチャ履歴を忘れる。** 2024年9月の初登場以降、複数の期間限定集音でピックアップされています。取り逃しても、復刻は現実的な道であり、永久に失うわけではありません。

## よくある質問

**ショアキーパーはどの武器タイプを使いますか？**
ショアキーパーは増幅器使いです。つまり、片手剣や長刃のキャラクターより武器プールが狭く、彼女にとって最良の選択肢はクリティカル系ステータスではなく共鳴効率やHPを提供するものです。

**良いショアキーパー武器構成に専用武器は必要ですか？**
いいえ。専用の星5増幅器は最強の選択肢ですが、共鳴効率サブステータスを持つ星4増幅器があれば、コストの何分の一かで彼女の核心的な要求を満たせます。ほとんどのプレイヤーは、武器の差よりも先に精錬度と音骸の品質の差を実感するでしょう。

**無課金で最高のショアキーパー武器は何ですか？**
コミュニティの総意は、共鳴効率サブステータスを持つ星4増幅器で、中でもVariationが最も頻繁に推薦されています。彼女の共鳴解放稼働率の問題を解決するものであり、彼女のキットで最大の性能レバーです。

**共鳴効率は過剰になることがありますか？**
はい。エンド・ループが毎回のローテーションサイクルで確実に使用できるようになったら、追加の共鳴効率は効果が薄れます。代わりにサブステータスをHP%へ移し、回復量とバフ値を高めましょう。

彼女の武器は、稼働率を第一に、スケーリングを第二に、自身のダメージは決して重視せずに組みましょう。そうすれば、ショアキーパーは静かにチームで最も価値のある枠になります。
