ショアキーパーは鳴潮でもっとも柔軟なサポーターの一人であり、同時にステータス画面がチームのダメージを左右する数少ないキャラクターでもあります。彼女のER要件を間違えればステラレルムの維持が崩れ、メインアタッカーが頼りにしていた会心率と会心ダメージもろとも失われてしまいます。逆にER要件をきっちり満たせば、すべてのローテーションがほとんどコストのかからない無料のダメージバフへと変わります。

このガイドでは、彼女の共鳴効率が実際に何をするのか、目標とすべき数値、そしてサブステータスを1つも無駄にせずそこへ到達するための武器・音骸・ローテーションを掘り下げます。

## 共鳴効率がショアキーパーを定義する理由

ショアキーパーはレクティファイアーを扱う回折属性の共鳴者で、黒海岸の守護者——テティスシステムが危機に直面したときに現れる謎めいた「第二インスタンス」——を務めています。戦闘において、彼女のキットのすべては1つのリソースに集約されます。それが共鳴エネルギーです。共鳴解放「エンドループ」は発動コストが高く、固有スキル「セルフグラビテーション」は基準値を超えた共鳴効率をチーム全体の会心率と会心ダメージに変換します。

この組み合わせこそが彼女を異例な存在にしています。ほとんどのサポーターにとって共鳴効率は快適さのためのステータス——あれば嬉しいが必須ではないものです。しかしショアキーパーにとってはダメージステータスです。共鳴効率の1ポイントは二度報われます。1度目はステラレルムを維持することで、2度目は味方が頼る会心バフを膨らませることで。ER要件を逃せば、その両方を同時に失うことになります。

| アビリティ | 種類 | 共鳴効率に関わる理由 |
|---|---|---|
| オリジンカリキュラス | 通常攻撃 | クールダウンの隙間を埋め、フィールド上でエネルギーを生成する |
| カオスセオリー | 共鳴スキル | 回復ループの中核であり、すべてのローテーションの固定要素 |
| エンドループ | 共鳴解放 | あなたのER予算のすべてがこの高コスト発動のために存在する |
| アストラルコード | フォルテ回路 | 解放と解放の間におけるフォルテゲージの報酬 |
| ライフエントワインド | 固有スキル | エネルギーコストの伴わないパッシブなサポート価値 |
| セルフグラビテーション | 固有スキル | 基準値を超えた共鳴効率をチームの会心バフに変換する |
| プルーフオブエグジスタンス | 変奏スキル | 交代のたびに得られる無料の登場ユーティリティ |
| バイナリバタフライ | 終奏スキル | 交代した瞬間にチームバフを付与する |

補足として整理しておくと、彼女のステラレルムはローテーションの軸となる回復兼バフのフィールドであり、アストラルコードは解放と解放の間の報酬ウィンドウです。プルーフオブエグジスタンスとバイナリバタフライは、どの戦闘でも繰り返す交代パターンに組み込まれます。必要なときにエンドループが準備できていなければ、これらはすべて機能しません。

## ショアキーパーのER要件：目標とすべき数値

このガイドから1つだけ数字を覚えるなら、これです。コミュニティの検証によれば、彼女の共鳴効率スケーリングの会心バフは共鳴効率およそ250%で頭打ちになります。それは上限であり、入場料ではありません。ほとんどのプレイヤーは200%から250%の間に落ち着き、エンドコンテンツも快適にクリアしています。

| 共鳴効率 | 体感（コミュニティ検証） | 評価 |
|---|---|---|
| 180%未満 | エンドループがローテーションごとに間に合わず、バフが切れる | ビルドを組み直す |
| 180～200% | ER武器を積んだエネルギー豊富なチームなら実用可能 | 最低ライン |
| 200～230% | 安定した維持、会心バフは強力だが最大ではない | 多くのプレイヤーに推奨 |
| 230～250% | ERスケーリングバフの上限付近 | エンドゲーム向けの理想 |
| 250%以上 | バフ変換がカンストし、余分なERは何もしない | 止めて振り分け直す |

これらの範囲は絶対の教義ではなく、プレイヤーの経験値として受け止めてください。異なるチーム、武器、音骸セットをまたいで集められたコミュニティ報告に基づくものであり、あなた自身の結果はチームの残りが彼女のためにどれだけエネルギーを生み出すかによって変わります。

### なぜ250%という数字がみんなに引用されるのか

ショアキーパーの固有スキルは、100%を超える共鳴効率をチーム全体の会心率と会心ダメージに変換します。この変換には上限があるため、追加のERがダメージを増やさなくなる地点が存在します。コミュニティの検証では、その地点は一貫しておよそ250%とされています。それ未満ではバフの価値をテーブルの上に置き去りにしています。それを超えれば、何の意味もないものにステータス予算を使っています。

### もっと少なくても済むケース

すべてのアカウントで上限を追いかける必要はありません。チームが素早くエネルギーを生成する場合——頻繁な交代、エネルギー効率の良い味方、短い戦闘——200%から220%でも実戦では同じように感じられることがよくあります。音骸の選択肢が限られる序盤のプレイヤーは、最後の数%を追う前にまず200%を安定して到達させることに集中すべきです。

## ER目標に到達する方法：武器、音骸、サブステータス

| 供給源 | 影響度 | 備考 |
|---|---|---|
| レクティファイアーの武器サブステータス | 非常に高い | モチーフの星5はER重視。星4のVariationは低予算の選択肢 |
| 音骸のメインステータス | 高い | 3コスト枠が共鳴効率%を入れる定番の場所 |
| 音骸のサブステータス | 中程度、ただし積み上がりが速い | 複数の部位にまたがるER%ロールはすぐに合計される |
| 音骸セット効果 | 中程度 | Rejuvenating Glowなどのサポートセットが回復役としての役割を補強する |
| チームのエネルギー生成 | 変動的 | 高速交代チームは彼女に明らかに多くのエネルギーを供給する |

武器が最大の変動要因です。ショアキーパーのモチーフ星5レクティファイアーは共鳴効率を軸に設計されており、装備すると合計が一気に20%以上動くこともあります。持っていない場合、星4レクティファイアーのVariationが標準的な低予算の答えです。そのサブステータスが共鳴効率そのものだからです。

| 音骸コスト | メインステータス優先度 | ERとの関連 |
|---|---|---|
| 4コスト | 会心率、会心ダメージ、または治療効果アップ | 通常はバフや回復の価値に充てる。ERは別の場所から取る |
| 3コスト | 共鳴効率% | 主要なER供給源——ほとんどのビルドはここで確保する |
| 1コスト | 攻撃力%またはHP% | ERはないが、彼女の回復とダメージの下限を安定させる |

音骸を厳選するときは、すでに有用なメインステータスを持つ部位なら共鳴効率サブステータスはキープ扱いにしてください。サポートセットを1式揃えるのは骨の折れる作業であり、ERの付いた部位を捨てることは、プレイヤーがER要件に届かず足踏みするもっともよくある原因の1つです。

## チーム構成とローテーション：ER要件がどう変わるか

共鳴効率は固定の目標ではありません——チームに対して相対的な目標です。他のキャラクターが生成するエネルギーが多く、交代の回数が多いほど、ショアキーパーが自分のステータス画面で背負う必要は少なくなります。

| チーム状況 | 推奨ER | 理由 |
|---|---|---|
| 長時間フィールドに立つDPS1人のハイパーキャリー | 230～250% | 交代が少ないほど彼女に流れるエネルギーも減る |
| 高速交代または2DPSチーム | 200～230% | 頻繁なスキルと交代が追加のエネルギーを生む |
| 音骸の選択肢が限られる序盤 | 180～200% | 利用できるER供給源が少ない。維持を優先する |
| フィールド探索や短い戦闘 | 180%以上 | 2回目の解放の前に戦闘が終わることが多い |

標準的なローテーションはこうです。プルーフオブエグジスタンスで登場し、カオスセオリーを発動し、フォルテゲージをアストラルコードに消費し、エンドループを放ち、バイナリバタフライでメインアタッカーへ交代する。彼女のフィールド滞在時間を急がないでください——彼女が表に出ている間に生成するエネルギーは、あなたが前提としている予算の一部です。フィールド時間を切り詰めることは、紙の上の数値が問題なく見えていても、ER要件を静かに下回る方法です。

もう1点考慮すべきこと：ローテーションで彼女が長くフィールド外に置かれるなら、250%に近い数値を見積もってください。その場にいないエネルギーは生成できません。

## ショアキーパーの共鳴効率を台無しにするよくあるミス

| 症状 | 考えられる原因 | 対処 |
|---|---|---|
| ローテーションごとにエンドループが間に合わない | ERが低すぎる | 3コストをER%に変えるか武器を変更する |
| チームの会心バフが弱く感じる | ERがバフ上限を下回っている | 250%に向けて引き上げる |
| 250%を超えても目に見える効果がない | 過剰投資 | ロールを会心、攻撃力、HPに振り分け直す |
| セットアップ中に倒れる | 生存性のサポートがない | 音骸を調整するか防御役の味方を連れて行く |

表以外にも、こうした癖に注意してください：

- **すべての部位にERを盛る。** 上限を超えたら、そのロールは会心やHPにできたはずの死にステータスです。
- **武器を確認せずにビルドをコピーする。** レクティファイアーのERサブステータスは、音骸3回分のロールよりも価値があることがあります。
- **1回の戦闘だけでERを検証する。** 共鳴効率が十分か判断する前に、ボス戦でフルローテーションを回してください。
- **チームの残りを無視する。** 味方が効率よくエネルギーを生成すれば、ショアキーパーのER要件は小さくなります。

彼女の正確なアビリティテキストやスケーリングを、又聞きの数値ではなく自分の目で確認したいなら、[鳴潮公式サイト](https://wutheringwaves.kurogames.com/en/)と[Wuthering Waves Wikiのショアキーページ](https://wutheringwaves.fandom.com/wiki/Shorekeeper)の2つをブックマークしておく価値があります。彼女のキットは「Till the Sea Turns Clear」の集音での登場以来安定しており、後の復刻でも同じなので、古いガイドも依然として通用します——ただし、プレイしているバージョンは常に再確認してください。

## FAQ

**ショアキーパーの理想的なER要件は？**
コミュニティの見解では、共鳴効率およそ250%がERスケーリングの会心バフが最大になる地点とされています。多くのプレイヤーにとって、220%から240%が現実的で効果的な目標であり、維持と他のステータスのバランスを取れます。

**共鳴効率200%でショアキーパーは機能しますか？**
はい、特にエネルギーを素早く生成する高速交代チームでは機能します。200%ならほとんどのコンテンツで安定したエンドループの維持ができますが、キットから会心バフを最大限に絞り出せるわけではありません。確かな出発点であり、終着点ではありません。

**この目標を達成するのにモチーフ武器は必要ですか？**
いいえ、ただしあると非常に楽になります。モチーフの星5レクティファイアーは共鳴効率を軸に設計されており、星4のVariationはサブステータスがERであるため、もっとも一般的な低予算の代替品です。どちらもなければ、3コスト音骸のメインステータスとERサブステータスにより頼ることになります。

**ショアキーパーに共鳴効率を盛りすぎるということはありますか？**
あります。バフ変換がカンストしたら、余分なERはチームのダメージに何の貢献もしません。上限を大きく超えているなら、キットの残りがエネルギー生成に追いつくよう、そのロールを会心、攻撃力、HPに移してください。
