## ショアキーパーのウルトは実際に何をするのか

ショアキーパーは、鳴潮のバージョン1.3「海が澄み渡るまで」の集音で登場した。開催期間は2024年9月29日から10月24日までで、2025年4月17日から4月28日にかけてバージョン2.2で復刻した。実装当初から、プレイヤーは彼女をヒーラーというよりバフエンジンと表現してきた——その理由こそショアキーパーのウルトである。

彼女の共鳴解放はエンドループと呼ばれる。単発のダメージ爆発として存在するのではなく、チームの周囲にサポート状態を確立する。近くの共鳴者のHPを回復し、アクティブな共鳴者に会心系のバフを重ねる。これらのバフは一度きりの詠唱ではなくフィールド上に残るため、ショアキーパーのウルトはその背後にあるステータスと同じくらいタイミングが重要になる。

他のすべてのボタンは、エンドループをより頻繁に使用可能にし、適切な瞬間に発動させるために存在するため、キット全体を文脈で見ると理解しやすい。

| 通常攻撃 | オリジン・カルキュラス | クールダウン間にフォルテを溜めるための繋ぎ |

物語では、ショアキーパーは黒海岸の守護者であり、「第二のインスタンス」として知られる。ソノロスフィアと高純度の残響エネルギー結晶で構成され、テティスシステムを導き、黒海岸が最も彼女を必要とする時に現れる存在だ。この守護者という枠組みは、彼女のゲームプレイを考える上で有用である。ショアキーパーのウルトは戦いを戦うのではなく、戦いを勝てる状態に保つのである。

## ショアキーパーのウルトが戦力倍増装置である理由

鳴潮のほとんどのヒーラーは一つの問題を解決する：チームを生かし続けることだ。ショアキーパーはその問題を解決し、さらに静かに二つ目の問題を解決する。すなわち、あなたのダメージの上限を引き上げるのだ。

会心ステータスは乗算的である。つまり会心率や会心ダメージへのバフは、アタッカーのあらゆる行動をスケールさせる——通常攻撃、共鳴スキル、共鳴解放のすべてだ。だからこそ、コミュニティの報告では彼女の個人ダメージが目立たなくても、サポートのティアリストで常に上位に位置づけられる。

| ウルトが提供するもの | 実戦で重要な理由 |
| --- | --- |
| チーム全体の回復 | ほとんどの編成で二人目の専用ヒーラーを不要にする |
| 会心率と会心ダメージのサポート | 会心参照のDPS全員の出力を倍増させる |
| アクティブ共鳴者に紐づくバフフィールド | バフが交代で無駄にならず、フィールド上のキャラクターに追従する |
| ダメージウィンドウ全体をカバー | メインDPSがバフ内でローテーションを一通り叩き込める |
| 一枠で二役 | 二人目のダメージディーラーかサブDPSのための枠を空ける |

実用的な結果はチーム経済の優位性だ。DPS＋ヒーラー＋サポートを回す代わりに、多くのプレイヤーはダメージディーラーを二人にして、ショアキーパーのウルトに生存性と増幅の両方を担わせる。これが、彼女が複数のバージョンアップデートをまたいで第一線に留まり続けている大きな理由である。

## ショアキーパーのウルトをチャージしてローテーションする方法

### エネルギー回復が実質的なクールダウン

エンドループはコストが高く、ショアキーパー自身はそれほど速くエネルギーを生成しない。つまり、ショアキーパーのウルトがどれだけ頻繁に使用可能になるかを決めるのは、回復量でもHPでもなく、実質的にエネルギー回復のステータスである。

コミュニティの報告では、快適さの観点からエネルギー回復が最優先され、HP割合がそれに続き、回復ボーナスはその後とされることが多い。DPSウィンドウが開く時にウルトがまだチャージ中なら、バフは遅れ、ローテーションは崩壊する。

| ステータス優先度 | その位置に来る理由 |
| --- | --- |
| エネルギー回復 | DPSの準備が整った時にエンドループが使えるかを決める |
| HP% | 彼女の回復は自身のHPプールに基づく |
| 回復ボーナス | 快適さを高めるが、壊れたローテーションを直すことは稀 |
| 固定HP | 音骸サブステータスの埋め草としては有用だが、目標ではない |

### 繰り返し可能なローテーション

エネルギー回復が安定して感じられたら、手順そのものが体に染みつく。目標は単純だ。ダメージディーラーがクールダウンを使い始める前に、フィールドを展開しておくこと。

| 手順 | 行動 | 目的 |
| --- | --- | --- |
| 1 | 存在証明で登場 | エネルギー消費なしの無償価値 |
| 2 | カオス理論を発動 | チームを回復し、フォルテを溜め始める |
| 3 | 通常攻撃とアストラル・コード | スキル再チャージ中にフォルテとエネルギーを補充 |
| 4 | エンドループを発動 | フィールド展開、回復と会心バフが有効化 |
| 5 | バイナリー・バタフライで退場 | バフをDPSへ引き継ぐ |
| 6 | ダメージウィンドウを回し、リセット | ウルトが再チャージされたら繰り返す |

クリーンな立ち回りと雑な立ち回りを分けるコツが一つある。ショアキーパーのウルトが点灯した瞬間に撃ってはいけない。メインのダメージディーラーがバーストウィンドウに踏み込む直前まで保持するのだ。誰も攻撃していない間に減っていくバフは、エネルギーを払って使わなかったバフである。

## ショアキーパーのウルトを軸にした編成：仲間とステータス

ショアキーパーはほぼ万能のサポートだが、会心に依存し、長時間途切れずにフィールドに留まるダメージディーラーと最も相性が良い。短くバースト的なローテーションのキャラクターは、出続けて攻撃し続けられるキャラクターよりもフィールドから得られるものが少ない。

| チームタイプ | ダメージディーラーの例 | 相性が良い理由 |

| 回折ハイパーキャリー | 今汐 | 長いフィールド滞在時間が会心バフを継続ダメージに変換する |

武器面では、ショアキーパーは整流器を使用し、彼女のモチーフ武器は回復とバフ維持を楽に感じたいプレイヤーに広く推奨されている。回復重視の音骸セットは多くのコミュニティビルドの標準的な出発点であり、サブステータスは上の表で示した通りに優先される。

一般的な全体像ではなく正確なアビリティ数値が欲しい場合は、[鳴潮公式サイト](https://wutheringwaves.kurogames.com/en/)がゲーム情報を直接公開しており、[コミュニティ管理のショアキーパーwikiページ](https://wutheringwaves.fandom.com/wiki/Shorekeeper)は彼女のキット、共鳴チェーン、集音履歴を照合する最速の場所である。

## 共鳴チェーン：追う価値はあるか？

ショアキーパーの共鳴チェーンは縦方向の投資であり、ほとんどのプレイヤーにとっては任意である。基本キットはすでに、ショアキーパーのウルトが有名な役割を果たしている。シーケンスは彼女のサポートとしての個性を深めるものであり、できることを変えるものではない。

| ノード | 名前 |
| --- | --- |
| 1 | 語られざる推測 |
| 2 | 夜の贈り物と拒絶 |
| 3 | 無限が私を待つ |
| 4 | 溢れる静寂 |
| 5 | 静寂の残響 |
| 6 | 新世界へ |

リソースをどこに使うか決めているなら、無凸ショアキーパーに快適なエネルギー回復ビルドを施す方が、ウルトがチームのダメージウィンドウと一度も噛み合わない高凸ショアキーパーよりも優れた働きをする。シーケンスの段階は贅沢品であり、ローテーションのタイミングは必須事項である。

避けるべきよくあるミス：

- 恩恵を受けるDPSがフィールドにいない状態でエンドループを発動する
- ステータス画面で回復数値が問題なく見えたからといってエネルギー回復を怠る
- バイナリー・バタフライで退場するのを忘れ、バフの引き継ぎを無駄にする
- 彼女を純粋なヒーラーとして扱い、周囲に攻撃的サポート価値を一切積まない
- 彼女の登場スキルを飛ばす。これは交代のたびに無償価値がある

## FAQ

**ショアキーパーのウルトは何と呼ばれますか？**
エンドループ、彼女の共鳴解放です。近くの共鳴者を回復し、会心重視のバフを付与するため、ダメージ爆発ではなくサポート用のアルティメットです。

**ショアキーパーのウルトはダメージを与えますか、それとも回復だけですか？**
回折ダメージにも貢献しますが、本当の価値は生成するフィールド——チームの回復と会心増幅にあります。プレイヤーはダメージではなくバフのために彼女を編成します。

**ショアキーパーのウルトにはどれくらいのエネルギー回復が必要ですか？**
正確な閾値はチームと音骸サブステータスによりますが、コミュニティの報告では一貫してエネルギー回復が彼女の優先リストの最上位にあります。逆境の塔でローテーションを試し、DPSウィンドウが開く前にウルトが準備できるまでエネルギー回復を追加してください。

**ショアキーパーのウルトを軸にビルドする価値はまだありますか？**
はい。会心参照のダメージディーラーがメタを定義し続ける限り、一枠で回復とダメージ倍増を両立するサポートは、どのアカウントでも最も安全な投資の一つであり続けます。
