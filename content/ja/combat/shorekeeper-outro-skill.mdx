## ショアキーパーのアウトロスキルが思った以上に重要な理由

多くのプレイヤーはショアキーパーの性能を逆から覚えてしまう。アルティメットの回復フィールドばかりに注目し、彼女がフィールドを離れる瞬間を無視している——そしてそここそが、最もチームに優しい効果が発動する瞬間なのだ。ショアキーパーのアウトロスキル「バイナリ・バタフライ」は、ありふれたスワップを命を救うスワップへと変えてくれる。

ショアキーパーのアウトロスキルを理解することが重要なのは、鳴潮が素早く意図的なキャラクター交代を評価するゲームだからだ。アタッカーがフィールドに立った瞬間に着地する回復は、あらゆるローテーションを滑らかにし、しかもコストはタイミングの良さだけしかかからない。いつ発動するのかを体に叩き込めば、クリアは目に見えて安定する——特に、一発の被弾でそのランが終わってしまう逆境の塔のフロアではなおさらだ。

このガイドでは、バイナリ・バタフライが実際に何をするのか、どうすれば確実に発動できるのか、誰が最も恩恵を受けるのか、そしてどんな癖が知らず知らずのうちにこのスキルを無駄にしているのかを分解して解説する。

## ショアキーパーのアウトロスキルが実際に何をするのか

ショアキーパーは、ヒーラー兼サポート枠を担う星5のスペクトロ共鳴者だ。彼女のアウトロスキルは「バイナリ・バタフライ」という名前で、ゲーム内の他のすべてのアウトロスキルと同様に**手動で発動することはできない**。コンチェルトゲージが満タンの共鳴者がフィールドから外れたときに自動で発動し、効果は次に登場する共鳴者に適用される。

ゲーム内のツールチップによれば、バイナリ・バタフライは対象にスペクトロダメージを与えつつ、登場する共鳴者のHPを回復する。この二重の役割こそが要点だ：サポートは退場する際に少しだけダメージに貢献し、入場する際にアタッカーをカバーする。正確な数値はショアキーパーのレベル、スキル投資、HPステータスに応じて変動するため、リソースを注ぎ込む前にフォルテ画面で現在の数値を確認しておこう。

この設計からは、実践上3つの帰結が導かれる：

- **貯めておくことはできない。** コンチェルト満タンでスワップした瞬間に解決される。いざという時のために取っておくことはできない。
- **HP投資が二重に働く。** 回復は彼女のHPに依存してスケールするため、HP%の音骸（エコー）やHPサブステータスは、フィールド回復とこのスキルの両方を強化する。
- **純粋なサポート行動ではない。** 対象にもダメージを与えるため、ショアキーパーを退場させることは決して完全なダメージロスにはならない。

| 項目 | 詳細 |
| --- | --- |
| スキルタイプ | アウトロスキル |
| ゲーム内名称 | バイナリ・バタフライ |
| 発動条件 | コンチェルト満タンの状態でショアキーパーをスワップアウト |
| 主効果 | 登場する共鳴者のHPを回復 |
| 副次効果 | 対象にスペクトロダメージ |
| 主なスケーリング | ショアキーパーのHPとスキルレベル |
| 手動発動の可否 | 不可 — 完全自動 |

## キット全体と、アウトロスキルの位置づけ

アウトロスキルだけを単体で知っていても十分ではない——それはローテーションに組み込まれるものだ。ここでは公式のスキル名を使い、ショアキーパーのフォルテ一式がどう並ぶかを示す。

| スキル枠 | 名称 | 実践での役割 |
| --- | --- | --- |
| 通常攻撃 | オリジン・カルキュラス | クールダウン中にコンチェルトを稼ぐ |
| 共鳴スキル | カオス・セオリー | 中核となる回復フィールドと布石 |
| 共鳴解放 | エンド・ループ | チーム全体の回復とサポートの時間帯 |
| フォルテ回路 | アストラル・コード | 回復を強化する強化状態 |
| 固有スキル | ライフ・エンタングルド | パッシブのユーティリティ強化 |
| 固有スキル | セルフ・グラビテーション | パッシブのユーティリティ強化 |
| イントロスキル | プルーフ・オブ・エグジスタンス | 彼女がフィールドに登場したときに発動 |
| アウトロスキル | バイナリ・バタフライ | 彼女がフィールドを離れたときに発動 |

リズムはシンプルだ：登場し、回復手段を設置し、コンチェルトを稼ぎ、然るべきタイミングで退場してバイナリ・バタフライが次に来るキャラクターをカバーする。彼女のイントロスキルとアウトロスキルは鏡写しの関係にある——一方が彼女の時間帯を開き、もう一方がそれを閉じてバトンを前に渡すのだ。

スキル名や現在の数値を確認したい場合は、[鳴潮の公式サイト](https://wutheringwaves.kurogames.com/en/)が共鳴者の紹介やパッチノートを公開しており、実際のテキストを確認できる。

## ローテーション：ショアキーパーのアウトロスキルを安定して発動させる方法

新規プレイヤーから最も多く聞かれる不満は、回復が「発動しなかった」というものだ。実際には、ほぼ常にコンチェルトが満タンになる前にスワップしたことを意味している。

| 手順 | 行動 | 重要な理由 |
| --- | --- | --- |
| 1 | プルーフ・オブ・エグジスタンスでスワップイン | 彼女の時間帯が始まり、コンチェルトの蓄積が始まる |
| 2 | カオス・セオリーを発動 | 回復フィールドを早い段階で設置する |
| 3 | 通常攻撃とアストラル・コードを使用 | コンチェルトリングを最速で満たす |
| 4 | チームが耐久を必要とするときにエンド・ループを発動 | 彼女のフィールドと次に来るアタッカーのバーストを重ねる |
| 5 | コンチェルトリング満タンでスワップアウト | これがバイナリ・バタフライを発動させる |
| 6 | 即座にDPSコンボを開始 | 回復はすでに入場時から作用している |

この流れを安定させるコツは2つある。1つ目は、彼女のクールダウンではなくコンチェルトリングを見ること——アウトロスキルを左右する唯一の要素はリングだ。2つ目は、安全な遠距離にいるキャラクターではなく、これから被弾するキャラクター**へ**スワップすること。一度も触れられないキャラクターに適用された回復は、無駄なスループットにすぎない。

コミュニティの報告では、アルティメット直後にショアキーパーをクイックスワップで退場させるのが最も綺麗に重なり合うとも言われている。フィールド回復と入場回復が重なって、短時間ながら非常に安全な時間帯が生まれるからだ。

## バイナリ・バタフライに最適な仲間

ショアキーパーのアウトロスキルは、長くコミットした火力時間帯を持つキャラクターにフィールドを引き渡すときに最も輝く。モーション中に罰を受けるガラスキャノン型のアタッカーが最も恩恵を受ける。

| パートナー | 属性 | 相性が良い理由 |
| --- | --- | --- |
| ジンシ | スペクトロ | 長いチャネルダメージが入場回復と噛み合う |
| カメリア | ハボック | 削りダメージを受けやすい攻撃的な近接コンボ |
| ジヤン | エアロ | バースト時間帯のフィールド滞在時間が長い |
| シャンリー・ヤオ | エレクトロ | 回避の余地が少ないコミット度の高いローテーション |
| カルロッタ | グレシオ | 遠距離だが、準備中の安全性は依然として有益 |

ショアキーパーは、すでに2人目のサポートかサブDPSを入れているほぼすべてのチームに組み込める。彼女が間違った選択になることはほとんどない——ただ、すでに快適に耐久できているチームでは*不要*な選択になることはある。

## ショアキーパーのアウトロスキルを無駄にするミス

以下は、プレイヤー体験スレッドや協力プレイのロビーで最も頻繁に見られるミスだ。

| ミス | 何が起きるか | 対策 |
| --- | --- | --- |
| コンチェルトが満タンになる前にスワップ | アウトロスキルが一切発動しない | リングが満タンになるのを待ってからスワップする |
| 安全なキャラクターへスワップ | 回復が無駄になる | アクティブなアタッカーへスワップする |
| 緊急ボタンとして扱う | 取っておくことはできない | ダメージが来る前にスワップを計画する |
| HPステータスを無視 | 回復もダメージもスケールが下がる | 音骸とメインステータスでHP%を優先する |
| サポートの二重積み | 回復が冗長になり、ダメージを失う | 2人目のヒーラーではなくサブDPSと組ませる |

最も高くつくミスは「緊急ボタン扱い」だ。バイナリ・バタフライはスワップ時に自動で解決されるため、緊急時のために取っておくことはできない。今すぐ回復が必要なら、1秒前にスワップしておく必要がある——つまり、ローテーションに反応するのではなく、計画しておくということだ。

## 知っておきたい共鳴チェーンノード

ショアキーパーの共鳴チェーンには6つのノードがあり、それぞれに固有の名前が付いている。コミュニティの議論では一般に、序盤のノードは控えめなユーティリティ強化、終盤のノードはより目に見えるパワースパイクとして扱われているが、正確な価値はビルド次第だ。

| ノード | 名称 | プレイヤー報告による優先度 |
| --- | --- | --- |
| S1 | アンスポークン・コンチェクチャー | 快適な早期の停止点として挙げられることが多い |
| S2 | ナイツ・ギフト・アンド・リフューザル | 堅実な中位の強化とよく評される |

ほとんどのプレイヤーにとって、正直なアドバイスはシンプルだ：ショアキーパーはS0でも十分機能する。彼女のアウトロスキルは共鳴チェーンへの投資なしで役割を果たすので、ノードを狙うのは、すでにこのキャラクターが好きで追加の快適さを求める場合だけでよい。

## ショアキーパーのアウトロスキルを最大限活かすためのクイックヒント

- **ダメージスキルより回復スキルを先に上げる。** アウトロスキルの回復こそ、チームが実際に体感する部分だ。
- **攻撃力ではなくHPを盛る。** 彼女のキットで有用なものはすべてHPに依存している。
- **逆境の塔に持ち込む前に、フィールドでの戦闘でスワップを練習する。**
- **クールダウンではなくコンチェルトリングを数える。** ここで重要な唯一のゲートだ。
- **回復を二重にしない。** チームにすでに専任の耐久役がいるなら、代わりにサブDPSを連れて行こう。

ショアキーパーはバージョン1.3の集結「海が澄み渡るまで」で注目の星5として初登場し、その後も復刻している——なので、新規プレイヤーは彼女が永久に入手不可能だと思い込むべきではない。初登場を見逃した人は、今後のバナーに注目しておこう。

## よくある質問

**ショアキーパーのアウトロスキルはレベル上げする価値がありますか？**
はい、彼女を主要な耐久役として使うなら価値があります。バイナリ・バタフライは彼女のキットの中でチームが直接恩恵を受ける2、3の要素のうちの1つなので、共鳴スキルや解放と並んでスキル投資に値します。

**ショアキーパーのアウトロスキルは回復ですか、ダメージですか？**
両方です。ツールチップには、対象にスペクトロダメージを与えつつ、登場する共鳴者のHPを回復すると記載されています。だからこそ、彼女を退場させることが純粋なロスに感じられないのです。

**コンチェルトゲージが満タンでなくてもショアキーパーのアウトロスキルは発動できますか？**
いいえ。鳴潮のアウトロスキルは、コンチェルトリングが完全に満タンの状態で共鳴者がフィールドから外れたときにのみ発動します。リングが満タンでなければ、何も起こりません。

**ショアキーパーは誰にスワップすべきですか？**
メインアタッカーに、理想的にはそのバースト時間帯が始まる瞬間に。そうすれば入場回復がローテーションで最も危険な部分をカバーし、ショアキーパーのアウトロスキルが安全な遠距離に立っているキャラクターに無駄遣いされずに済みます。
