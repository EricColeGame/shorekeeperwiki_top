## ショアキーパーのキットがダメージ以上に重要な理由

ショアキーパーは、チームのダメージ上限を静かに書き換えるタイプのサポートであり、彼女のショアキーパーキットを理解することが、そこに到達する最速の方法です。彼女は黒海岸出身の回折共鳴者で、回復、バフ、ローテーションの安定化を同時に行います — だからこそ、デビューからずっと経った今でも終盤の編成に登場し続けています。もし彼女を引いたものの、何を押せばいいかわからないなら、このガイドではショアキーパーキットのすべての部分を平易な言葉で解説します：アビリティ、共鳴チェーン、ビルドの優先度、チーム編成。

彼女は公式には「第二のインスタンス」および黒海岸の守護者として知られ、ソノロスフィアと高純度の残響エネルギー結晶で構成されていると言われる存在です。設定はさておき、戦場で重要なのはシンプルです：彼女はチームを生かし続け、メインダメージディーラーにもっと大きな攻撃チャンスを与えます。

| クイックプロフィール | 詳細 |
| --- | --- |
| 元素 | 回折 |
| 戦闘ロール | サポート／ヒーラー |
| 別名 | 「第二のインスタンス」、黒海岸の守護者 |
| 主なスケーリング | HPと共鳴効率 |
| 固有メカニクス | チームを回復・強化するフィールド効果 |
| 実装バージョン | 1.3、「海が澄み渡るまで」集音 |

新しく彼女を手に入れた人が最もよくする間違いは、彼女をサブDPSとして扱うことです。彼女はそうではありません。彼女の個人ダメージは設計上控えめで、投資するポイントはすべてHP、共鳴効率、回復量に回す方がはるかに良いです — それが彼女のフィールドを維持し、バフを流し続ける要素です。

## アビリティ解説：ショアキーパーキットのすべてのボタン

彼女のフォルテは一つのアイデアを中心に構築されています：回復フィールドを設置し、チャージし、それをチーム全体の攻撃力に変換する。各アビリティは次のアビリティにつながります。

| アビリティ | 名称 | 効果 |
| --- | --- | --- |
| 通常攻撃 | オリジン・カルキュラス | 標準的な攻撃コンボ。主にフォルテを溜め、待機時間を埋めるために使用 |
| 共鳴スキル | カオス・セオリー | 核心となるセットアップボタン — 回折ダメージを与え、フィールド効果を開始 |
| 共鳴解放 | エンド・ループ | チーム全体の大回復とバフの窓。キットの心臓部 |
| フォルテ回路 | アストラル・コード | フォルテがチャージされると解放される強化状態／攻撃 |
| 固有スキル | ライフ・エンタングルド | 回復と持続力を支えるパッシブ |
| 固有スキル | セルフ・グラビテーション | ステータスをより強力なチームバフに変換するパッシブ |
| 登場スキル | 存在の証明 | 彼女のローテーションをスムーズに始める登場攻撃 |
| 退場スキル | バイナリ・バタフライ | 彼女のバフを次に登場する共鳴者に引き継ぐ |

### 通常攻撃：オリジン・カルキュラス

オリジン・カルキュラスは彼女の価値が宿る場所ではありませんが、それでも使うことはあります。クールダウン中に数回の通常攻撃でフォルテチャージを溜め、強化状態に早く到達できます。この攻撃を強くするために攻撃ステータスに過剰投資しないでください — それは罠です。

### 共鳴スキル：カオス・セオリー

カオス・セオリーはすべてを始めるボタンです。回折ダメージを与え、その後のアビリティの基盤となるフィールド効果を確立します。実際には、ローテーションの早い段階でこれを発動し、チームの残りがその中で戦えるようにしたいです。

### 共鳴解放：エンド・ループ

エンド・ループは報酬です。コミュニティの検証では、彼女の回復とチーム強化の大部分がここで発揮されると一貫して報告されており、だからこそ多くの編成に組み込まれます。チーム全体の「リセットボタン」として扱いましょう — DPSが最大ダメージの窓にコミットしようとするときに発動します。

### フォルテ回路：アストラル・コード

アストラル・コードは彼女の強化状態です。チャージされると、フィールドを維持しながら意味のある回折ダメージを与えることができます。嬉しいボーナスであり、メインイベントではありません。

### 固有スキル：ライフ・エンタングルドとセルフ・グラビテーション

この2つのパッシブは、ショアキーパーキットが静かに効率化する部分です。ライフ・エンタングルドは持続力を強化し、セルフ・グラビテーションは彼女が実際に求めるステータスを積むことで報酬を与えます — ビルドの選択が直接チームバフに変わります。

### 登場と退場：存在の証明とバイナリ・バタフライ

存在の証明は彼女にスムーズな登場を与えますが、覚えておくべきはバイナリ・バタフライです。彼女の退場スキルは彼女を「バフをかけて去る」サポートにするものです：彼女をローテーションに入れ、キットを発動し、スワップアウトして次の共鳴者に恩恵を引き継がせます。

> **ヒント：** 正確な倍率はバランスパッチで変わります。リソースを投入する前に、必ずゲーム内または[鳴潮公式サイト](https://wutheringwaves.kurogames.com/)で現在の値を確認してください。

## 共鳴チェーン：追う価値のあるノード

ショアキーパーの共鳴チェーンはよくあるパターンに従います：初期ノードはキットを滑らかにし、中間ノードは実際のパワーを加え、最後の2つは熱心な課金者向けの贅沢品です。

| ノード | 名称 | コミュニティ評価 |
| --- | --- | --- |
| S1 | 語られざる推測 | 快適枠 — キットの流れを改善 |
| S2 | 夜の贈り物と拒絶 | 強力なアップグレード。最良の停止点としてよく挙げられる |
| S3 | 無限が私を待つ | コアアビリティへの堅実なスケーリング強化 |
| S4 | 溢れる静寂 | 状況次第。長期戦で有用 |
| S5 | 沈黙の残響 | ほとんどのアカウントでは漸進的 |
| S6 | 新世界へ | 重課金者向け — 強力だが高価 |

ほとんどのプレイヤーにとって正直な答えは：彼女の基本キットはすでに完成しています。プレイヤー体験では、S0のショアキーパーがサポートに必要なすべてを行うと報告されており、コピーは必需品ではなく贅沢品です。もし1つアップグレードを望むなら、多くのガイドが指摘するのはS2です。

## ショアキーパーキットに合わせたビルド：ステータス、音骸、武器

彼女の回復とバフはHPと共鳴効率にスケーリングするため、彼女のビルドはDPSキャラクターと比べて驚くほどシンプルです。個人ダメージのためにクリティカルロールを追う必要はありません。

| 優先度 | ステータス | 理由 |
| --- | --- | --- |
| 1 | HP% | 回復量とバフ強度を直接増加 |
| 2 | 共鳴効率 | アルティメットが増える = 回復とバフの窓が増える |
| 3 | 治療効果 | キットがすでに行うすべてを倍増 |
| 4 | 固定HP | それ以外は死にロールの有用な埋め草 |
| 5 | 回折ダメージ | 本当にアストラル・コードのダメージが欲しい場合のみ |

コミュニティ報告からの実用的なビルドノート：

- **共鳴効率は捨てステータスではありません。** 毎回のローテーションでエンド・ループを安定して発動できないと、キット全体が停滞します。他の何かを追う前に、快適な閾値を目指しましょう。
- **音骸セット：** チームの持続力を高める回復志向のセットは彼女と自然に合います。一方、退場後に次に登場する共鳴者をバフするサポートセットも人気の選択肢です。どちらも機能します — チームがより多くの生存性を必要とするか、より多くのダメージを必要とするかで選びましょう。
- **武器：** 彼女の専用5つ星オプションは明らかに最適ですが、低予算の共鳴効率増幅器も見事に機能します。武器バナーに強制されていると感じないでください。
- **サブステータス：** HP%と共鳴効率をほぼ何よりも優先。固定攻撃力とクリティカルロールは彼女には無駄です。

限られた武器の天井をどこに使うか決めるなら、サポート武器は通常、新しいDPSキャラクターよりも見返りが悪いです。ショアキーパーは4つ星でも問題なく機能します。

## チーム編成とローテーションのヒント

ショアキーパーはほぼ万能です。回復とダメージの窓を求めるチームに合い、実際にはゲーム内のほぼすべてのチームに適合します。

| チームアーキタイプ | コア例 | 機能する理由 |
| --- | --- | --- |
| 回折ハイパーキャリー | 回折メインDPS + サブDPS + ショアキーパー | 単体大型ヒットのバースト窓を増幅 |
| 通常攻撃DPS | 攻撃重視DPS + バッファー + ショアキーパー | 絶え間ない回復でDPSをより長くフィールドに維持 |
| 焦熱／凝縮キャリー | 元素DPS + サポート + ショアキーパー | 万能枠 — 特定の元素を要求しない |
| 二重サポート | DPS + 2人目のヒーラー／バッファー + ショアキーパー | 高難度エンドゲームモードでの極めて高い安全性 |

**練習する簡単なローテーション：**

1. ショアキーパーで開始し、カオス・セオリーでフィールドを確立。
2. アストラル・コードが必要なら、短い通常攻撃コンボでフォルテを溜める。
3. DPSがコミットする準備ができたらエンド・ループを発動。
4. チャージされていればアストラル・コードを使用し、スワップアウト。
5. バイナリ・バタフライで彼女のバフをメインダメージディーラーに引き継ぐ。

内面化する価値のあるニュアンス：ショアキーパーの価値は*タイミング*にあり、稼働率ではありません。DPSが何もせず立っている間に彼女の解放を発動すると、キット全体が無駄になります。彼らのバースト窓に合わせましょう。

## FAQ

**ショアキーパーはヒーラーですか、バッファーですか？**
両方です、それがポイントです。ショアキーパーキットは強力な回復と意味のあるチーム全体の強化を同時に提供するため、純粋な医療者ではなく「回復とバフ」のサポートとよく表現されます。

**彼女のキットはどのステータスにスケーリングしますか？**
主にHPと共鳴効率です。HPは回復とバフ強度を左右し、共鳴効率は解放をどれだけ頻繁に発動できるかを決めます。クリティカルと攻撃力ロールはほとんど無駄です。

**彼女の専用武器は必要ですか？**
いいえ。コミュニティ報告では、低予算の共鳴効率増幅器でも十分に機能することが一貫して示されています。専用武器はアップグレードであり、必需品ではありません。

**今日でも引く価値はありますか？**
ほとんどのアカウントにとって、はい。万能サポートは、手持ちのどんなDPSにも組み込めるため、長持ちします。すでにヒーラーが充実していない限り、彼女はゲーム内で最も安全な長期投資の一つであり続けます。

## 最終的な感想

ショアキーパーキットは、順序を理解するプレイヤーに報います。彼女は派手ではなく、ダメージチャートのトップには立ちません — しかし、チームの他のすべてのキャラクターをより強く殴らせ、より長く生き残らせます。HPと共鳴効率のためにビルドし、キャリーがコミットする準備ができたらエンド・ループを発動し、あとはバイナリ・バタフライに任せましょう。そのループをマスターすれば、彼女なしでチームを回していたなんて信じられなくなるでしょう。
