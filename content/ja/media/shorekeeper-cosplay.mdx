ショアキーパーは『鳴潮』でもとりわけ目を引くキャラクターの一人であり、ショアキーパーのコスプレは、その幻想的で星を導くような存在感をイベント会場に持ち込む最速の方法です。漂うような淡いレイヤー、冷たい銀髪、水晶のような杖は、人混みの中でもすぐにそれと分かり、そして驚くほど写真映えします。このショアキーパー コスプレガイドでは、彼女のポーズを形作る設定、制作全体を支える生地と小道具、そしてイベント前に本当に完成させるための現実的なスケジュールを順に解説します。

## ショアキーパーが多くの制作を刺激する理由 — そして最初に知っておくべきこと

ショアキーパーは『鳴潮』にプレイアブルな回折の共鳴者として登場し、最初のピックアップバナー「海が澄むまで」は2024年9月下旬から10月下旬まで、バージョン1.3で開催されました。その後、2025年4月のバージョン2.2で復刻されました。鎧の戦士やストリートウェアのスタイリストが揃う中で、彼女は兵士というより神話のように見えるため、際立っています。

その対比こそがコスプレイヤーを惹きつけます。彼女のシルエットは、重い装甲ではなく、長く漂う布パネルとクリスタルのアクセントで構成されているため、ショアキーパーのコスプレは小道具作りと同じくらい、柔らかい衣装の縫製が報われます。コミュニティの制作者たちは彼女をよく「フォトグラファー向けのキャラクター」と表現します — ハンガーにかかっているときよりも、布に風を受けて動いているときのほうが映えるデザインです。

ここでは設定がいつも以上に重要です。なぜなら、彼女の性格は見た目の中で最も偽装しにくい部分だからです。布を裁つ前に知っておく価値のある要点をいくつか挙げます：

- 彼女は黒海岸の守護者であり、ゲーム内では「第二のインスタンス」と呼ばれています。
- 彼女の姿はソノロスフィアと高純度の残響エネルギー結晶で構成されていると説明されています。
- 彼女はテティス・システムと結びついており、星そのものを操ると言われています。
- 彼女は危機の時だけ現れ、黒海岸の真の指導者に応えます。
- 中国語名の「守岸人」は、おおよそ「岸を守る者」という意味です。

要するに、彼女は古く、遠く、そしてようやく感情を感じ始めたばかりです。カメラの前では、それは大きなアクションポーズではなく、静止、水平な視線、そして意図的な小さなしぐさとして表れます。

| 設定またはデザインの手がかり | 制作にどう落とし込むか |
| --- | --- |
| 回折属性 | ネオンではなく、温かみのあるアイボリーと淡い金色の発光アクセント |
| 黒海岸の守護者 | コントラストを出すための深いネイビーから黒のアンダーレイヤー |
| クリスタルの体とソノロスフィア | 半透明または玉虫色のフィルムとレジンのディテール |
| 星と星座のモチーフ | 繊細なシルバーのアップリケ、控えめなきらめき |
| よそよそしく、目覚めつつある性格 | 静止したポーズ、遠い視線、最小限の微笑み |

## 衣装制作：生地、構造、小道具

ほとんどのショアキーパー コスプレ制作は4つの領域に分かれます：レイヤードドレス、体に沿うボディスとカラー、装飾的なハードパーツ、そして杖です。それぞれを別の締め切りを持つ別プロジェクトとして扱いましょう。4つすべてを1週間で終わらせようとすると、衣装は未完成の山行きになります。

### 生地とシルエット

動く生地を選びましょう。シフォン、オーガンジー、クレープ、柔らかいサテンは、彼女のデザインが示すようにドレープし、光を捉えます。暗いアンダーレイヤーには、マットクレープやポンテを使うと、フラッシュの下でもコントラストが平坦に見えません。

経験豊富な制作者が常に繰り返す2つのルール：

1. **透けるものには必ず裏地を付ける。** イベント会場の照明は容赦ありません。
2. **生地は日光とフラッシュの両方で試す** — そうしないと、淡い白は写真で完全に白飛びします。

### 構造、フィット、ハードパーツ

良い生地に触る前に、ボディスのモスリン仮縫いを作りましょう。ショアキーパーの衣装は胴体部分が体に沿い、そこからボリュームへと広がるため、少しでも緩いボディスはシルエット全体を崩してしまいます。背中に隠しファスナーまたは編み上げパネルを付け、少し余裕を持たせましょう — これを8時間着ることになります。

胸と肩の装飾は、正確さが生きるか死ぬかの部分です。滑らかにヒートシールした表面のEVAフォーム、薄い湾曲パーツには熱可塑性樹脂、最も細かい部分には軽いレジンキャストが、コミュニティの標準的なアプローチです。プライマーを塗り、研磨し、薄いコートで塗装し、最後は重いグロスではなくサテンまたはパールのトップコートで仕上げます。

### 杖の小道具

彼女の杖は象徴的な要素であり、イベントの武器チェックで最も指摘されやすいパーツです。芯は軽くしましょう — PVCまたはフォームで包んだ木製ダボ — そして発光部分は取り外し可能にするか、隠しスイッチ付きの電池式にします。飛行機で移動する予定なら、杖はネジで結合する2つの半分に分けて作りましょう。

| 構成要素 | 難易度 | 一般的な素材 | 目安時間 |
| --- | --- | --- | --- |
| レイヤードスカートと背面パネル | 易しい〜中程度 | シフォン、オーガンジー、クレープ | 8〜12時間 |
| ボディス、カラー、袖 | 中程度 | サテン、ストレッチニット、接着芯 | 10〜16時間 |
| 胸と肩の装飾 | 難しい | EVAフォーム、熱可塑性樹脂、レジン | 12〜20時間 |
| 杖の小道具 | 難しい | PVC芯、EVAフォーム、アクリル、LED | 15〜25時間 |
| ウィッグの準備とスタイリング | 中程度 | シルバーホワイトのロングレースフロント | 4〜6時間 |

## ウィッグ、メイク、仕上げのディテール

彼女の髪は長く、淡く、柔らかく波打っています — 何の苦もなく見えるのに、決してそうではない種類のウィッグです。必要だと思う以上に時間を見積もりましょう。

- まずは**クールなシルバーホワイト**のロングレースフロントから始め、温かみのあるプラチナは避けます。
- きついカールではなくゆるやかな波には、太めのバレルアイロンを低温設定で使いましょう。
- 分け目は少しセンターからずらし、レースは軽い手つきで馴染ませて、生え際が自然に見えるようにします。
- ネットをかけたスタンドで保管しましょう。この長さは、ちょっとしたことで絡まります。

メイクは、肌をクールで清潔感のある印象に保ちます。ニュートラルクールなシェーディング、頬骨に沿った柔らかいハイライト、目頭付近に少しの淡い金色のシマーを入れると、昼光の下でもコスチューム感を出さずに異世界的な印象になります。淡い金色またはアンバーのカラコンで仕上げます — 度付きが必要なら早めに注文しましょう。カスタムオーダーには数週間かかります。

| ディテール | やること | 避けること |
| --- | --- | --- |
| ウィッグの色味 | クールなシルバーホワイト | 温かみのあるプラチナや黄色がかったブロンド |
| メイク | クールなシェーディング、控えめな金色のシマー | 濃い黒ライナー |
| ネイル | 短く、淡く、清潔に | 明るい色や欠けたポリッシュ |
| 発光要素 | 温かみのあるアイボリーまたは淡い金色 | 彩度の高いネオンカラー |
| ジュエリー | 繊細なシルバー、最小限 | 大ぶりの主張の強いアイテム |

## ポージング、撮影、レタッチ

ショアキーパーは、距離とスケールを感じさせる環境で最もよく撮れます。水平線、もや、開けた空があるものはすべて味方になります。

| ロケーション | なぜ機能するか | ベストな光 |
| --- | --- | --- |
| 岩がちな海岸線や防波堤 | 彼女の名に直接結びつく | ゴールデンアワー |
| 霧のある誰もいない浜辺 | 神話的で遠い印象になる | ブルーアワー |
| ヘイズマシンを使ったスタジオ | 杖の発光をコントロールできる | いつでも |
| 濡れた反射のある夜の街 | 古代と現代の対比 | 日没後 |
| 背の高い草や砂丘 | 風に舞う布の動きを見せられる | 午後遅く |

ポージングのメモ：あごは水平に保ち、静止を軸にし、布に演技をさせましょう。杖は握りしめるのではなく、手を添えるようにします。杖が光るなら、背景を少しアンダー露出で撮ってもらい、光が白飛びせずにはっきり見えるようにしましょう。レタッチでは肌の色味をクールに保ち、強い彩度は避けます — 彼女のパレットは意図的に落ち着いています。

## 予算、スケジュール、イベント当日

コミュニティの報告によると、ほとんどのショアキーパー制作は、どこまで自分で作るかによって3つの価格帯のいずれかに収まります。

| 価格帯 | 費用目安 | 含まれるもの | 向いている人 |
| --- | --- | --- | --- |
| 古着・DIY | $ | 中古のベース衣装、手切りフォーム、スタイリングし直したウィッグ | デザインを試したい初心者 |
| ミドルレンジ制作 | $$ | オーダーメイド縫製のドレス、スタイリング済みウィッグ、フォーム＋LEDの杖 | よくイベントに行く人 |
| プレミアム制作 | $$$ | 縫製依頼、レジン装飾、プロによるウィッグ | コンテストやポートフォリオ撮影 |

ここでは予算よりもスケジュールのほうが重要です。これほど軽い生地は、急いだ裾を許してくれません。

| イベントまでの時間 | 集中すること |
| --- | --- |
| 10〜12週間前 | 参考資料を集め、生地を買い、ウィッグを注文する |
| 8〜10週間前 | ドレスとボディスを縫う |
| 6〜8週間前 | 装飾と杖を作る |
| 3〜4週間前 | ウィッグをスタイリングし、メイクテストを行う |
| 1〜2週間前 | 衣装を全部着てリハーサルとテスト撮影 |
| 前日 | 修理キットを詰め、すべての電池を充電する |

修理キットには、合う色の糸、布用テープ、ホットグルースティック、予備電池、安全ピン、小さなスチーマーを入れておきましょう。細部は常に[『鳴潮』公式サイト](https://wutheringwaves.kurogames.com/en/)とゲーム内のキャラクタービューアで照合し、ファンアートだけに頼らないようにしましょう。ファンの解釈は時間とともにずれていくからです。

## よくある質問

**ショアキーパーのコスプレは初心者には難しいですか？**
ドレスは仕立てよりもドレープに頼るため、初心者向けです。難しいのは装飾と杖なので、多くの初心者は衣装を自分で縫い、小道具は依頼または購入します。

**ショアキーパーのコスプレにはいくらかかりますか？**
価格帯によってまったく異なります。古着と手作りで作るバージョンは少額の予算でも揃えられますが、レジンキャストの杖とプロがスタイリングしたウィッグを含む完全依頼のショアキーパー コスプレは、700ドル以上になることもあります。

**どのウィッグカラーを買うべきですか？**
クールなシルバーホワイトです。温かみのあるプラチナや黄色がかったブロンドは、彼女のデザインのクールな色調と衝突し、フラッシュ撮影では黄色く見えがちです。

**杖をイベントに持ち込めますか？**
まず、参加するイベント固有の小道具ポリシーを確認してください。ほとんどのイベントでは、小道具は軽量で、金属製でなく、発射物を放てないことが求められます。取り外し可能なLED芯を備えたフォーム＋PVCの杖なら、通常は問題なく検査を通過します。
